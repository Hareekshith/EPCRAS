# EPCRAS

**Enterprise Patch Compliance and Risk Assessment System**

EPCRAS is a web-based cybersecurity application for monitoring software patch compliance across organizational IT assets. It aims to identify vulnerable software, assess associated risks, and prioritize patches based on security impact.

## Tech Stack

- Python / Flask
- SQLite
- HTML / Jinja2
- Bootstrap
- JavaScript

## Status

🚧 **Under Development**

The project is being developed incrementally as part of a Software Engineering project.

## Planned Features

- Asset and software inventory
- Vulnerability tracking
- Patch compliance analysis
- Risk-based patch prioritization
- Compliance dashboard and reports
