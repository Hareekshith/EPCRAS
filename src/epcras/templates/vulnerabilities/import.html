CSV Header Format Requirements

Your CSV file should contain the following column headers (case-insensitive):

cve_id, software, vendor, description, cvss_score, severity, affected_versions, fixed_version, patch_available, exploit_available, published_date
  • cve_id (Required): e.g. CVE-2024-3094
  • software (Required): e.g. xz-utils
  • vendor (Required): e.g. Tukaani
  • cvss_score (Required): Floating point number between 0.0 and 10.0
  • severity (Required): One of LOW, MEDIUM, HIGH, CRITICAL
  • patch_available: true / false or yes / no
  • exploit_available: true / record false
  • published_date: Date formatted as YYYY-MM-DD
